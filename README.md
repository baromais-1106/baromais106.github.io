Personal Portfolio - Mai Đào Hoài Bảo

Mô tả dự án
Đây là website hồ sơ  cá nhân được thiết kế theo kiến trúc Single Page Application (SPA). Dự án giúp trưng bày thông tin cá nhân, kỹ năng phát triển phần mềm, thiết kế cơ sở dữ liệu và các dự án thực tế tiêu biểu. 

Các tính năng nổi bật:
- Kiến trúc SPA:Điều hướng mượt mà giữa các mục (Info, Dự án, Kinh nghiệm, Sở thích...) thông qua JavaScript mà không cần tải lại trang.
- Responsive Design: Bố cục linh hoạt sử dụng CSS Flexbox & Grid, hiển thị tối ưu từ điện thoại di động (<576px) đến màn hình desktop (≥992px).
- Trải nghiệm người dùng (UX) Hỗ trợ tính năng Lightbox cho Gallery và các hiệu ứng chuyển trạng thái tương tác.
- Mã nguồn sạch: Mã nguồn được tổ chức theo tiêu chuẩn, tách biệt rõ ràng giữa cấu trúc (HTML), giao diện (CSS) và logic điều khiển (JS).

Công nghệ sử dụng
- HTML5, CSS3, Vanilla JavaScript.
- Môi trường phát triển: Visual Studio Code.
