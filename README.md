Personal Portfolio - Mai Đào Hoài Bảo

Mô tả: 
Đây là website hồ sơ  cá nhân được thiết kế theo kiến trúc SPA, giúp trưng bày thông tin cá nhân, kỹ năng phát triển phần mềm, thiết kế cơ sở dữ liệu và các dự án thực tế. 

Các tính năng nổi bật:
- Kiến trúc SPA: Điều hướng mượt mà giữa các mục (Info, Dự án, Kinh nghiệm, Sở thích...) thông qua JavaScript mà không cần tải lại trang.
- Bố cục linh hoạt sử dụng CSS Flexbox & Grid, hiển thị tối ưu từ điện thoại di động (<576px) đến màn hình desktop (≥992px).
- Trải nghiệm người dùng (UX): Hỗ trợ tính năng Lightbox cho Gallery và các hiệu ứng chuyển trạng thái tương tác.
- Mã nguồn được tổ chức theo tiêu chuẩn, tách biệt rõ ràng giữa cấu trúc (HTML), giao diện (CSS) và logic điều khiển (JS).

Công nghệ sử dụng
- HTML5, CSS3, Vanilla JavaScript.
- Môi trường phát triển: Visual Studio Code.

Bản quyền & Tài nguyên
- Quyền sử dụng: Có thể tham khảo và sử dụng mã nguồn cho mục đích học tập cá nhân.
- Typography: Sử dụng font chữ [Inter](https://fonts.google.com/specimen/Inter) do Google Fonts cung cấp.
